# Support

## Documentation

Start with the README, which covers installation, configuration, and the
command reference. The `secrets`/`versions`/`headers` subcommands expose
structured queries; `anansi help` lists everything available.

## Getting help

- Open an issue for bugs and feature requests (see
  [CONTRIBUTING.md](CONTRIBUTING.md)).
- The repository is hosted under `github.com/QYVORA/qyvora-anansi`. For
  issues on other QYVORA projects, use their respective repositories.
- Report security vulnerabilities privately per [SECURITY.md](SECURITY.md) —
  never in a public issue.

## Operating responsibility

ANANSI is an **authorized-use** tool. Only assess targets you are allowed to
reconnoiter. It is single-target by design; broad or internet-wide scanning is
out of scope. Confirm authorization with the documented
`--authorized`/`QYVORA_AUTHORIZED` mechanics and review `SECURITY.md` before
use in an organization.
