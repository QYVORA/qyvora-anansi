# Vulnerability classes used by the exploit-chain engine.
# Format: <class-id>|<class name>|<keyword1,keyword2,...>|<exploitation technique>
# Keywords are matched case-insensitively against a finding's title (substring
# match).  A finding may map to more than one class.
#
# -- Entry / recon ---------------------------------------------------------------
info-disclosure|Sensitive Information Disclosure|info disclosure,disclosure,exposed,directory listing,backup,user enumeration,php info,debug log,error log,heapdump,env file,environment file,git config,git repository,svn repository,lockfile,dump,robots.txt,sitemap,source map,composer,package.json,readme,swagger,api docs,openapi,graphql,graphiql,config file,settings file,crossdomain,.ds_store,phpinfo,profiler,actuator,secret,logs,makefile,travis,test script,site archive,asset links|Harvest exposed files, directory listings, version banners, and configuration. Use the leaked data as a foothold or as credentials for a later step.
dns-misconfig|DNS Misconfiguration|dns,dangling,cname,subdomain takeover,domain takeover,nxdomain|Register the service behind a dangling CNAME or NS record to hijack the subdomain and impersonate the organisation.
open-redirect|Open Redirect|open redirect,url redirection,url redirect|Craft a URL that redirects to a phishing or malicious site to harvest credentials or tokens.
crypto|Improper Cryptographic Implementation|weak encryption,weak hash,improper cryptographic,md5,sha1,weak cipher,missing hsts,tls,ssl,certificate,cipher suite,expired certificate,self-signed|Exploit weak transport, ciphers, or certificates to decrypt, intercept, or impersonate traffic.

# -- Access -----------------------------------------------------------------------
credentials|Default/Weak Credentials|default credential,weak credential,default password,weak password,brute-force,credential stuffing,password reuse,xml-rpc,secret|Test common and default credentials against discovered login endpoints and use leaked secrets for lateral movement.
exposed-admin|Exposed Admin Interfaces|admin panel,admin interface,administrator panel,adminer,phpmyadmin,login page,login exposed,admin exposed,wordpress admin,console endpoint,shell endpoint,admin endpoint|Locate exposed management consoles and gain access with default, weak, or brute-forced credentials.
auth-bypass|Authentication Bypass|authentication bypass,auth bypass,access bypass,account takeover,account creation,bypass,session fixation,login bypass,session management|Defeat the authentication mechanism to reach protected functions without valid credentials.
broken-authz|Broken Authorization|improper access control,broken authorization,authorization bypass,insecure direct object,unauthorized access,unauthenticated access|Call privileged endpoints or manipulate object identifiers to access resources without authorization.
bola|Insecure API Authorization (BOLA)|bola,idor,broken object level,api authorization,insecure api,api endpoint,object reference|Enumerate object identifiers through API calls to access or modify other users' resources.
privesc|Privilege Escalation|privilege escalation,privesc,privilege|Exploit the flaw to elevate access from a normal user to an administrator or root.
csrf|Cross-Site Request Forgery|csrf,cross-site request forgery,xsrf|Trick an authenticated victim into submitting forged state-changing requests.
race-condition|Race Condition|race condition,time-of-check,toctou,double-spend|Race multiple requests against a state change to bypass a check (coupons, transfers, signups).
business-logic|Business Logic Flaws|business logic,logic flaw,abuse function,workflow bypass,rate limit|Abuse application workflows such as pricing, limits, or approvals for unauthorized benefit.

# -- Injection / execution ---------------------------------------------------------
command-injection|Command Injection|command injection,os command,shell injection|Inject shell metacharacters into the vulnerable parameter to execute OS commands.
sql-injection|SQL Injection|sql injection,sqli|Craft malicious SQL payloads to extract data, bypass authentication, or write files on the database server.
xss|Cross-Site Scripting|xss,cross-site scripting,content injection,html injection|Inject client-side scripts that run in a victim's browser to steal tokens, sessions, or perform actions as the user.
ssrf|Server-Side Request Forgery|ssrf,server-side request forgery|Point the vulnerable request at internal addresses to read metadata, access internal services, or probe the intranet.
path-traversal|Path Traversal / Arbitrary File R/W|path traversal,directory traversal,lfi,file read,arbitrary file,local file inclusion|Traverse the filesystem with ../ sequences to read or write files outside the web root.
deserialization|Insecure Deserialization|deserialization,unserialize,object injection|Send a crafted serialized payload to trigger object injection, leading to code execution or data corruption.
xxe|XML External Entity|xxe,xml external entity,external entity|Embed external entities in XML input to read local files or probe internal services.
ssti|Server-Side Template Injection|ssti,template injection|Inject template-engine syntax into input that the server renders, leading to code execution.
ldap-injection|LDAP Injection|ldap injection|Manipulate LDAP filter expressions to bypass authentication or enumerate directory entries.
nosql-injection|NoSQL Injection|nosql injection,mongodb injection|Inject operator syntax into NoSQL queries to bypass authentication or extract data.
file-upload|Insecure File Upload|file upload,unrestricted upload,upload bypass,webshell|Upload a malicious file such as a webshell to achieve code execution on the server.
rce|Remote Code Execution|rce,remote code execution,code execution|Exploit the vulnerable input or endpoint to execute arbitrary code on the server.

# -- Memory / infra ----------------------------------------------------------------

cloud-misconfig|Cloud Misconfiguration|cloud misconfiguration,bucket,s3,aws,azure,gcp,insecure storage,public bucket,docker|Exploit misconfigured cloud storage, containers, or permissions to read or modify data.
container-escape|Container Escape|container escape,docker socket,privileged container,docker environment|Abuse container privileges or the Docker socket to break out into the host.
dependency-vuln|Dependency/Supply Chain Vulnerabilities|dependency,cve,vulnerable version,outdated|Exploit known CVEs in outdated dependencies or components for code execution, data access, or lateral movement.
dependency-compromise|Dependency/Supply Chain Compromise|supply chain,dependency confusion,typosquatting,malicious package,compromised dependency|Abuse package-name confusion or a compromised registry to push malicious code into the supply chain.
